# V2 ideas (not in v0.1.0)
- Multi-turn leakage (student escalates over several turns); more pressure styles.
- Partial credit: "within one step" localization; per-error-type confusion matrix in README.
- Natural-language (LaTeX) rendering of steps alongside SymPy syntax; ask models for an explanation and grade it.
- More error types: wrong product rule, arithmetic slip, wrong integration bound, sign of g in kinematics.
- Systems of equations, inequalities, vectors; problems with 2+ injected errors.
- CI (GitHub Actions) running `pytest` + `stepthree check` on every push; nightly free-tier eval.
- Model-family coverage (Qwen / DeepSeek / Llama) once they are on a free tier again.

## Realism: beyond clean synthetic slips
- **Conceptual-misconception mutations (keeps the SymPy proof):** (a+b)^2 -> a^2+b^2, sqrt(a+b) -> sqrt(a)+sqrt(b),
  log(a+b) -> log(a)+log(b), d/dx a^x -> x*a^(x-1), wrong kinematics formula, mixed sign conventions.
  Same gate as v0.1.0: kept only if check() == k.
- **External-validity track on real (LLM-made) errors:** score the same models on ProcessBench
  (first-wrong-step labels by human experts, step-by-step free response, not MCQ) and report the rank
  correlation with StepThree. Download at run time; check the licence before redistributing. Caveats:
  public, so possible training contamination; labels are human, not proofs.
- **Real student working:** JEE itself is computer-based MCQ/numerical, so it yields no written steps.
  Sources with written steps: CBSE/state board Class 12 long answers (step-marked), coaching practice
  sheets and rough work, homework. Needs consent and anonymisation; even 30-50 solutions would be rare data.
- Note: Eedi misconception data is MCQ (misconception-tagged distractors), with no steps, so it is useful
  only as a source of misconception *types* for the mutations above.
- **ErrorRadar** (2,500 K-12 items with labelled error step) for *vision* models: every item needs its image, so it was not usable in the text-only v1 (see DECISIONS D17).
- **Harder problems:** upgrade the 14 easy problems in REVIEW.md (alg02, alg03, alg05, alg10, alg13, alg15, alg16, alg17, phy02, phy05, phy07, phy08, phy11, phy15) to multi-concept JEE Main level, keeping >= 40 unit_mixup items; then rerun inject + eval (new items invalidate old runs).
